Common HTTP statuses

            
    
              
  • 401 — Token missing, invalid, or expired. Create a new token or re-authorize OAuth.
    • 
              
  • 403 — Your account does not have permission for that resource.
    • 
              
  • 404 — Course or path not found, or the Canvas URL is wrong.
    • 
              
  • 429 — Canvas rate limit. Wait and retry; Hub already backs off once or twice.
    • 
              
  • 5xx / 502 — Canvas or the Hub proxy could not complete the request.
